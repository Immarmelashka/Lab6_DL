# Action Recognition Pipeline (8 Frames Classificator)

Лабораторная работа по распознаванию действий сотрудников магазина (`inaction`, `move`, `work`) по сериям из 8 последовательных изображений.

## Ссылка на веса модели
Скачайте обученный файл весов **`best_super_cnn.pth`** по ссылке ниже и положите его в корень этого репозитория перед сборкой Docker-образа:
https://drive.google.com/drive/folders/1mr5UQwEUlbCG2BEyQhjE-iSxqV3dpsSJ?usp=drive_link

##  Инструкция по сборке и запуску в Docker

### 1. Сборка Docker-образа
Убедитесь, что скачанный файл `best_super_cnn.pth` находится в одной папке с `Dockerfile`. Запустите сборку:
```bash
docker build -t action_model .
```

### 2. Запуск классификации папки
Чтобы скрипт внутри контейнера смог прочитать папку с вашего компьютера, мы прокидываем её через локальный том (`-v`). 
Замените `/home/user/my_test_sequence` на реальный абсолютный путь к папке с вашими 8 изображениями на вашем ПК:

```bash
docker run --rm -v "/home/user/my_test_sequence:/app/test_data" action_model /app/test_data
```

### Что возвращает контейнер:
Контейнер обработает изображения, извлечет глобальные и локальные эмбеддинги MobileNetV3Large, посчитает оптический поток внутри маски человека и выведет финальный ответ в консоль:
`[РЕЗУЛЬТАТ]: work` (или `move`, `inaction`).
