# Двухпоточный Ансамбль классификации видеопоследовательностей ритейла

Промышленное решение по распознаванию действий сотрудников ритейла (`inaction`, `move`, `work`) по коротким сериям кадров и длинным трекам (папки `track` до 1000+ изображений).

## Ссылка на веса моделей
Для работы ансамбля требуются файлы весов обеих нейросетей. Скачайте их и положите в корень папки репозитория перед сборкой Docker-образа:
https://drive.google.com/drive/folders/1mr5UQwEUlbCG2BEyQhjE-iSxqV3dpsSJ?usp=drive_link
* В папке должны лежать два файла: `best_super_cnn.pth` (1D-CNN) и `best_3d_resnet.pth` (3D-ResNet18).

## Сборка и запуск в Docker

### 1. Сборка Docker-образа
```bash
docker build -t action_ensemble .
```

### 2. Запуск классификации трека
Контейнер поддерживает обработку папок любого размера (как 8 кадров, так и длинных треков). Прокиньте путь к папке с изображениями через локальный том:

```bash
docker run --rm -v "/абсолютный/путь/к/тестовой_папке:/app/test_data" action_ensemble /app/test_data
```

### Описание архитектуры ансамбля (Soft Voting)
При инференсе контейнер параллельно запускает два потока вычислений:
1. **Поток 1D-CNN (Геометрия + Полярный поток):** Извлекает 8 равномерных кадров трека, вырезает силуэт человека через YOLOv8, генерирует эмбеддинги MobileNetV3Large и считает локальный оптический поток Фарнебека внутри маски человека. Поток идеален для классов динамики (`work` и `move`).
2. **Поток 3D-ResNet18 (Пространственно-временные пиксели):** Модель дообучена в среде Colab Pro с применением аугментаций и Early Stopping, достигнув **92.66% точности** на валидации. На инференсе использует алгоритм *Temporal Sliding Window*, сканируя длинный трек окнами по 16 кадров. Поток идеален для фиксации статики (`inaction`).

Вероятности классов взвешиваются и суммируются, что нивелирует ошибки локальных детекторов и обеспечивает устойчивость системы на зашумленных данных.
